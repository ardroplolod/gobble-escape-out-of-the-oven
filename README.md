**Gobble Escape: Out of the Oven** is an original third-person 3D Thanksgiving turkey escape game built with vendored Three.js, procedural PBR textures, and synthesized Web Audio. Outrun Farmer Jed across the Autumn Farmyard, Harvest Barn, and Thanksgiving Kitchen while dodging roaring cast-iron ovens, spinning carving knives, snap-traps, and gravy slicks to reach the Freedom Gate.

## Run it

```sh
node serve.ts
# Open http://127.0.0.1:8080 in desktop Chrome
```
